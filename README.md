# CyberQuest — Security Awareness Training

An interactive, browser-based security awareness training with scenario-based learning and downloadable certificates.

**Live app / Živá aplikace:** https://srameko.github.io/skoleni-kyberneticke-bezpecnosti/

---

## Features / Funkce

- **4 interactive scenarios** / **4 interaktivní scénáře:**
  - Phishing (suspicious email / podezřelý e-mail)
  - Device Code Phishing (MFA bypass)
  - Vishing (urgent payment call / naléhavý hovor o platbě)
  - Insider Threat (access bypass request / žádost o zkratku)
- **7 languages / 7 jazyků:** English, Français, Deutsch, Español, Italiano, **Čeština**, **Slovenčina**
- Score tracking with streak bonuses / Sledování skóre se sériovými bonusy
- Downloadable PDF certificate / Stáhnutelný PDF certifikát
- No server required — runs entirely in the browser / Nevyžaduje server — běží čistě v prohlížeči

---

## Jak začít / How to Start

1. Otevřete aplikaci v prohlížeči / Open the app in your browser
2. Vyberte jazyk pomocí vlajek nahoře / Select your language using the flag buttons at the top
3. Zadejte své jméno / Enter your name
4. Klikněte na **Zahájit školení** / Click **Begin Training**
5. Projděte všechny 4 scénáře / Complete all 4 scenarios
6. Stáhněte si PDF osvědčení / Download your PDF certificate
